# Запуск boolka для Windows

Новые выпуски распространяются только как автономный ZIP для Windows x64. .NET отдельно не нужен.

1. Скачайте `boolka-<версия>-windows-x64-standalone.zip`.
2. Распакуйте весь архив в отдельную папку, доступную для записи.
3. Запустите `boolka.exe`. Семь файлов лицензий сохраняйте рядом с приложением.

При необходимости создайте ярлык boolka.exe средствами Windows. Настройки хранятся отдельно в `%LocalAppData%\boolka`, поэтому перенос одной папки программы не переносит настройки. Удаление распакованной папки не удаляет настройки и игровые моды.

## Сборка ZIP

Нужны Windows и .NET 8 SDK. Inno Setup больше не используется.

```powershell
dotnet publish src/Boolka.App/Boolka.App.csproj -p:PublishProfile=WindowsStandalone -p:NuGetAudit=false -o app-<версия>-standalone -m:1
./scripts/Package-Windows.ps1 -SourceDirectory ./app-<версия>-standalone
```

Упаковщик создаёт ZIP и файл SHA256 в `distributions`, проверяет восемь файлов приложения/лицензий, отклоняет ссылки, проверяет содержимое архива и не перезаписывает старые выпуски.

Ранее выпущенные установщики сохранены. Механизм обновления уже установленных копий продолжает работать через ZIP.
