# boolka 0.42.1

- Полностью подсвечивается кнопка проверки обновлений при изменении файлов аддонов: фон, рамка и контрастный текст. Работает в установленных аддонах и каталоге.
- Нижняя строка состояния доступна для выделения и копирования; редактирование отключено.
- Исправлена установка Lost Treasure и других модов с похожими проектами библиотек: кандидаты, не обеспечивающие требуемую минимальную сборку, исключаются до проверки неоднозначности. Выбор наугад и ручные исключения по названиям не добавлялись.

Windows x64, автономный ZIP без отдельной установки .NET. Публиковать с тегом **v0.42.1** и приложить ZIP/SHA256.
