# boolka 0.41.9

Менеджер аддонов ESO для Windows x64. .NET отдельно устанавливать не нужно.

- **Установщик:** boolka-0.41.9-windows-x64-setup.exe — установка для текущего пользователя, меню «Пуск» и необязательный ярлык. Права администратора не нужны.
- **ZIP без установки:** boolka-0.41.9-windows-x64-standalone.zip — распакуйте все файлы и запустите boolka.exe.
- **Контрольные суммы:** boolka-0.41.9-SHA256SUMS.txt.

Добавлена тихая проверка обновлений приложения. Когда опубликована более новая стабильная версия, подсвечивается кнопка с круговыми стрелками. Всплывающих уведомлений о доступности версии нет; скачивание и замена файлов начинаются только по нажатию. Проверяются источник, размер, SHA256, состав архива и версия EXE. Старые файлы сохраняются для отката; незавершённая замена восстанавливается до обычного запуска.

Установщик и обновление приложения сохраняют настройки boolka и игровые файлы. Используется первая золотистая булочка как иконка приложения. Каталог ESOUI, установка/обновление модов, библиотеки, наборы и резервные копии сохранены.

Первую версию с кнопкой обновления установите вручную. Для её подсветки нужен публично доступный релиз с более новым номером. Проверка самой 0.41.9 не предлагает повторно установить 0.41.9.
