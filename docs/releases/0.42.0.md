# boolka 0.42

Техническая версия и тег GitHub: **0.42.0 / v0.42.0**. Это сохраняет совместимость с проверкой обновлений в 0.41.9.

- Ошибки и сообщения, требующие действия, выделяются розовым полужирным текстом. В светлой теме используется более тёмный розовый цвет для читаемости. Обычные сообщения и прогресс возвращаются к нейтральному виду.
- Если аддоны добавлены, удалены или изменены вне boolka, подсвечивается кнопка **Check for updates / Проверить обновления**. Нажатие перечитывает список; во время операции подсветка откладывается, после актуального сканирования снимается. Автоматической установки модов это не запускает.
- Выпуск распространяется как ZIP без установки. Тихая проверка обновлений самой boolka сохранена.

Для публикации прикрепите standalone.zip и SHA256SUMS.txt версии0.42.0, выберите обычный последний релиз с тегом v0.42.0. Не переименовывайте архив.
