# Наборы boolka

Сервер не требуется: набор — небольшой файл `.boolka` со списком ID ESOUI. Его можно отправить через мессенджер или разместить по ссылке.

## Создать и отправить

1. Откройте «Установленные» и нажмите **Export pack / Экспорт набора** внизу.
2. Выберите моды, введите название, при желании автора и описание.
3. Нажмите **Save pack / Сохранить набор**, выберите место для файла и отправьте этот файл другому пользователю.

Экспорт не содержит ZIP, локальных путей, SavedVariables и настроек игры. Моды без подтверждённого проекта ESOUI исключаются с указанием количества.

## Получить и установить

1. Выберите свою папку ESO AddOns.
2. Нажмите **Import pack / Импорт набора**, выберите файл `.boolka`.
3. Просмотрите состав, список устанавливаемых библиотек и причины пропусков.
4. Закройте ESO и нажмите **Install missing / Установить недостающие**.

Boolka получает текущие версии напрямую с ESOUI. Уже установленные проекты остаются без изменений, даже если для них есть обновления. Если нужна замена существующей библиотеки, сначала обновите её обычной кнопкой обновления и повторите импорт. Импорт не удаляет моды вне набора.

Если состав или версии меняются после просмотра, установка требует повторного просмотра. При ошибке одного пакета независимые установки продолжаются с прежними резервными копиями и откатом. Повтор не скачивает успешно установленные проекты.

## Изменить набор

Откройте файл через Import pack и нажмите **Edit copy / Изменить копию**. Можно изменить описание и состав; для добавления доступны также распознанные установленные моды. Сохраните копию под новым именем или явно подтвердите перезапись исходника. Ранее отправленные копии сами не обновляются.

## Ограничения первой версии

- Только ESO, от 1 до 100 уникальных ID в файле, не больше 100 пакетов вместе с зависимостями в плане.
- Устанавливаются текущие версии, точные старые выпуски не закрепляются.
- Игровые настройки и расположение панелей не переносятся.
- Нет общего онлайн-каталога, аккаунтов и автоматического обновления набора. Поле автора — текстовая подпись.
- Недоступные проекты, конфликтующие папки и исключённые пользователем пакеты пропускаются с объяснением.
- Файл содержит только данные. Неизвестные поля, произвольные ссылки, повторные ID/поля, неверная версия или игра, чрезмерный размер отклоняются.


## Проверка манифестов при импорте (0.41.1)

Перед подтверждением boolka загружает необходимые ZIP во временную папку, читает DependsOn/PCDependsOn из манифестов и уточняет вложенные зависимости. Только затем показывает итоговый состав набора с библиотеками. До подтверждения файлы в AddOns не меняются.

После подтверждения состав, версии и контрольные суммы сверяются со свежим каталогом. Изменение плана требует нового просмотра. Уже скачанные ZIP повторно используются при совпадении контрольной суммы, затем установщик заново проверяет их содержимое. Существующие аддоны и SavedVariables импорт не заменяет.

Проверка без сети: `dotnet build tests/PackImport.Manifests/PackImport.Manifests.csproj -m:1`, затем `dotnet tests/PackImport.Manifests/bin/Debug/net8.0/Boolka.Verification.dll`. Дополнительный аргумент `--live` явно включает проверку четырёх публичных проектов ESOUI на изолированной папке.
